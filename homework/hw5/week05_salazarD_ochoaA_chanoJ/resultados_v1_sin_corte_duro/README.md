# Corrida del mini torneo con la versión 1 del agente

Estos archivos son la evidencia que nos llevó a añadir el corte duro (`HARD_STOP`). Se generaron con `starter_v1.py`, que solo estima el tiempo antes de empezar cada profundidad. La jugada más lenta de nuestro agente fue de 586 ms, y perdió 3 partidas por tiempo. No se usan en el notebook como resultado final: las huellas de `metadata.json` corresponden a esa versión.
